## 导入与批次核对

1. 建议先复制世界，再导入`dist/FoodAndTable-0.7.2.mcaddon`。
2. 世界已启用的包列表中，确认行为包显示 **BP 0.7.2-trial.1**，资源包显示 **RP 0.7.2-trial.1**。相同版本号不足以证明同批次，两个完整标识必须匹配。
3. 执行`/function mcpe_food/build_info`查看运行中的BP标识，并与世界设置中的RP标识核对。两个包根目录的`mcpe_food_build.json`也保存同一标识；五附件摘要见`dist/SHA256SUMS.txt`。
4. 执行`/function mcpe_food/tasting_new`领取本轮21件新品，每种4个。额外测试旧壁挂和超市收款机，可用原有分类命令或创造栏取得。

分组命令：`clothing_store`（13）、`clothing_fixtures`（4）、`clothing_items`（9）、`transit_equipment`（3）；原`electronics`追加为46，`office_stationery`追加为9，`digital_ad_screens`仍是原9款广告屏。

## 统一实机验收顺序

1. **四面墙**：分别放置旧AED、诊断器械组、空调、白板、电视、相框、时钟，以及9款广告屏。正面向墙外，背板贴墙，文字正立、不镜像。检查已放置旧实例重新同步及新放置实例。
2. **收款机四向**：从东西南北分别放置。收银员主屏、扫码区和钱箱向放置者，顾客显示屏向反面。
3. **新品设备**：三款FT电脑正面、鼠标位置、固定红白政务画面；打开轻薄本屏幕与键盘垂直。站台屏和叫号屏各占2×1完整墙面，右侧背墙缺失或前方受阻应拒绝放置。
4. **衣物**：挂架拒绝帽子；双层架满4槽；人台按衣物部位陈列；试取回、满背包收架、保存重进及重新进入区块。
5. 分别检查普通／官方灵动视效；原版玻璃、画和其他原版资源应保持原样。

反馈请注明：BP／RP完整标识、具体物品、点击哪一面墙或玩家站位、新放还是旧记录恢复、普通或灵动模式，以及看到屏面还是背板。截图或短视频能帮助校准真实客户端。
