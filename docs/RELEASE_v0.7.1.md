# 方寸食光 / Food & Table 0.7.1

## 朝向与尺寸修复

- 用户反馈壁挂类摆件背板朝向放置者。修正全部7种壁挂摆件变体与9款电子广告屏的模型正面、背板位置和东西墙显示旋转；不改变已有实例的支撑、方向、yaw、revision或展示索引。固定画面在点击墙面外侧展示，放置后不追踪玩家。
- 数位板保持平放，修正上表面UV，让文字下沿对应玩家所在一侧；四向摆放规则不变，既有实例载入后使用修正外观。
- 输液泵与支架实际可见高度改为准确2格（32模型单位），延长立杆和管线、上移挂袋，泵体和底座比例保留。
- 壁挂空调按8/7同比放大，机身宽度从14增至16模型单位，约1格宽；继续使用单格完整背墙，锚点保持。
