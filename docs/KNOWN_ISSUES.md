## 已定位与已修改的历史问题

### K01 原版玻璃等资源被污染

- 历史现象：用户看到原版玻璃材质异常；根因路径为自定义纹理别名在全局合并时冲突。
- 已实现：0.1.1起使用mcpe_food私有别名、路径和几何ID；resource-safety与validate禁止原版／全局覆盖。
- 已验证：当前隔离检查通过。待实机确认原版外观；不得通过改原版玻璃、材质或全局光照补救。

### K02 破坏碎屑与官方光影

- 用户要求移除令人不适的新增方块碎屑，并适配官方光影。
- 已实现：destruction_particles.particle_count=0，私有中性回退；pbr能力和方块／实体纹理集。没有为此覆盖原版粒子或启用RTX门槛。
- 已验证：0.6.0的417个自定义方块零碎屑定义、PBR结构和区域通过。真实粒子、GPU与安卓效果仍待测。

### K03 笔记本／iPad角度与屏幕闪烁（实机结论尚未闭环）

- 证据：用户旧截图显示屏幕倾斜不符合要求，0.5.1原生X旋转与离线预览约定不一致。截图为历史反馈，当前仓库不依赖临时附件路径。
- 0.5.2改为向后110°烘焙坐标，按发行几何中心坐标测夹角和后倾方向；不再仅检查源rotation值。
- 0.5.3排查发现原MacBook屏幕49条中19条与壳体相交；独立分段即使源平面分开，也会互相穿入。另有微台阶漏面，斜视露出灰壳形成点阵。
- 已实现：同组屏幕／外壳共用1/8单位Y边界，源法向间隔0.10，连续UV和台阶贴面；避开摄像头／刘海／铰链重叠。其他倾角支架不强制共用该网格。
- 已验证：最终方块与实体模型角度、深度、UV和可见台阶自动检查；软件侧视／剖面预览。**未证明实机闪烁完全消失。**
- 下一步：先复现并检查双包实际版本／缓存，记录设备、模式、角度、距离，再改几何；不要回退到直接填写110°旋转、只查共面、镜像整张纹理或更改原版材质。
- 定位：tools/device-geometry.mjs、electronics-art.mjs、tests/patch-052.test.mjs、patch-053.test.mjs；预览laptop_angles、screen_sections。

### K04 设备背对玩家与鼠标左右

- 0.5.1曾支持任意角yaw，用户后续明确改为最近东南西北方向，正面朝放置者；此后不应恢复斜放。
- 无屏路由器／服务器原先因screenFront门控跳过方向计算。0.5.3分离placementFront，指示灯／硬盘托架为正面；旧无yaw摆件保留旧方向，重放才应用新计算。
- 台式机／一体机鼠标按正常面对屏幕在右侧修正，Mac Studio也检查右侧鼠标。不能用模型+x或单张图标左右代替用户视角。
- 自动四向、斜向玩家位置、中心后备、保存角度与旧记录测试通过；实际四侧放置仍待验收。未出问题的物品不要套用全局翻转。

### K05 厨具闪烁

- 0.4.3错开烤箱等面板、窗框、把手深度，删除内部面，静态检查同向共面重叠。

## 构建与维护问题

### M01 并行构建／过早测试造成半成品假失败

已发生两个build同时重建packs，引发缺失模型；也曾在优化结束前测试，model-report仍引用已删除的桌号重复几何。完整构建结束后复测通过，不能据此认定业务回归。**构建、优化、最终资源测试／校验、打包按依赖顺序执行**，不要同时启动多个npm run build／package，不在其间读取最终结果。

### M02 Windows偶发UNKNOWN／文件占用

曾在预览和报告写入时失败。fs-output.mjs已采用同目录临时文件、原子替换、跳过相同内容及对已知共享错误有限重试。未形成跨设备实测结论；若再次出现，收集具体路径、读取者与时序。不能用递归删目录、终止不明进程或删除正在使用的.git锁来“修复”。

### M03 生成文档和固定计数漂移（0.7.0已维护并通过本版检查）

- 本次发现DEVELOPMENT／ASSETS抬头及计数仍停留0.5.3，ADVERTISEMENTS只列12幅；本次只改文档纠正，不改生成器。
- build-v3生成CATALOG；service-previews、lifestyle-previews会追加文案；optimize-release生成STORAGE与报告。其中有0.6.0标题、41项、固定减98等时点常量，下次升级必须审查。
- optimizeRelease是完整构建的收尾步骤，不是对已优化包任意重跑的通用命令；重复独立调用可能使统计再次扣减或失去原始对比含义。
- archive-report.sourceArtworks=12是历史原图字段，不能当作广告总数；实际广告20幅，源主图路径分为originals与city，masters共20份。
- 0.7.0已将存储报告版本改为读取package、模型数量改为最终资源扫描，服务／家居预览文案读取目录。归档报告分开记录旧原图、纸面广告与电子屏；最终结果须本版校验通过后确认。

## K07 0.7.0壁挂背板朝人及数位板阅读方向（0.7.1修复待实机复验）

- 用户反馈：数位板、电子白板、电子广告屏背板朝向放置者，并补充所有壁挂类均如此。该反馈是实机现象证据，不以旧自动方向断言否定。
- 定位：0.7.0壁挂模型的屏面位于局部+Z，显示层共用旧方向表；测试仅检查记录字段与同一套方向辅助函数，未独立核对最终模型法向、背板及原生实体旋转。
- 修改：全部7个壁挂变体及9款电子屏进行仅壁挂的几何半转，背板归Z=0，显示层转换东西墙原生yaw；保持存档direction/yaw、旧索引和锚点。数位板仅调整顶部屏面UV，不翻转其他设备。
- 自动验证：193项测试及1,701,012项静态检查通过，覆盖最终几何、四面墙、数位板四向／斜向、旧记录恢复与未受影响几何基线。不能仅用screenNormal自证正确。
- 下一步：在0.7.1匹配双包、普通／灵动模式中实机复验；当前不宣称GPU与客户端问题已闭环。
