# 升级记录

## 0.5.0 · 2026-10-27

- 新增电子设备独立物品分组，包含台式机套装、一体机、四款笔记本的打开／合起款、路由器、服务器机柜、iPad Air与妙控键盘、CRT和键鼠套装，共15件。
- 全部使用原创128px UV图标、色图和MER，屏幕与状态灯限定低强度自发光；闭合笔记本不发光，不添加全局材质或光照覆盖。
- 复用持久桌面流程，完整方块、书架与半砖均贴面摆放；选择范围按实际模型生成，旧339种外观索引顺序保留。
- 新增electronics试用命令，tasting_new改为本版设备。旧分组命令、101道料理、53个菜单配方、全部ID和UUID保留。
- 提供设备总览、笔记本开合和背面支架细节预览；未进行Windows、安卓、灵动视效或真实联机游戏验收。

## 0.4.3 · 2026-10-27

- 新增12幅独立商业广告画，涵盖日式小吃2、西餐3、粤菜2、火锅1、中餐3、甜品店1，各提供三档尺寸，共36种展示。
- 新增一格三菜托盘，菜单选择三个位置分别装取，支持70种盘装内容；满载几何预算209。
- 餐具共14种，移入物品页独立分组；新增空高脚杯，仅珍品红酒可盛装其中。
- 10款饮品同时支持玻璃杯和马克杯，新增11种器皿组合，单品盛装组合共318种。
- 新增不可饮用的可口可乐和百事可乐纸杯摆件，旧可乐成品保留。
- 普通／雕纹书架、上下半砖和双层半砖可承载桌面摆设；下半砖使用贴面展示实体，支撑升高时同步定位。
- 修复已发现的厨具共面重叠，增加持久展示、菜单复核、回滚、加载恢复和重复实体清理。
- 扩展私有实体PBR及资源隔离校验；不覆盖原版画、材质、模型、贴图或光照，维持零破坏碎屑。
- 保留0.4.2全部已有ID、UUID、原配方、掉落和作物状态。发行包额外提供包含海报主图与排版的源码zip。

## 0.4.2 · 2026-10-27

- 西餐新增惠灵顿牛排、香草烤羊排、野菌烩饭、奶油焗龙虾、鱼子酱配薄饼、焦糖布蕾、黑松露鹅肝。

- 食物保持非金属且无自发光，鱼子、焦糖与鹅肝设置独立粗糙度。维持pbr能力、普通模式色图与私有资源路径，全部自定义方块零破坏碎屑。
- 保留0.4.1全部已有ID、UUID、原配方、掉落和作物状态；tasting_new发放本次七道，tasting_all_western扩展至23道。

## 0.4.0 · 2026-10-27

- 可食成品由63增至84：中餐新增8、日料新增7、甜品新增2、饮品新增4。
- 创造物品栏增加中餐、西餐、日料、甜品、饮品五个私有折叠组；厨具菜单同步合并旧菜系分类。

- 新资产使用128×128色图、UV、图标和MER，保持每个模型不超过256个方块体。原有资源隔离、杯子比例和零破坏碎屑规则延续。
