# 方寸食光 · Food & Table 0.5.4

主要用于Minecraft基岩版国际版创造模式的料理、餐桌、餐厅广告与电子设备附加包。现有 **102种可食成品、8种展示配菜、15种餐具、12幅广告画（36种尺寸）、2款铜锅、3款酒瓶、2款品牌纸杯摆件和35款电子设备及5款餐厅用品**；四种厨具、六种作物及53个原有菜单配方保留。

> 目标为国际版正式版26.52、Windows和安卓，无需实验性选项。编译、静态资源、模拟交互与离线预览可检查工程一致性；实际客户端导入、灵动视效、触屏、真实联机和密集摆放性能尚未验证。

## 导入与升级

1. 退出世界，打开 **dist/FoodAndTable-0.5.4.mcaddon**，等待两个包导入。也可分别导入行为包和资源包mcpack。
2. 世界设置中确认两个包均启用 **0.5.4**。建议先复制旧世界作为备份。
3. 在创造物品栏“物品”页查找五类料理、“餐具”、“广告画”、“电子设备”和“餐厅用品”分组，或搜索具体名称。
4. 若仍使用旧外观，完全退出Minecraft并重开，再检查世界实际启用版本。

保留旧物品、方块ID、UUID、原配方、作物状态及默认盛装ID。普通模式与灵动视效使用同一色图，所有资源位于本包私有空间，不覆盖原版画、材质、模型、贴图、粒子或世界光照。

## 0.5.4餐厅收银与服务台

新增触屏收银机、扫码支付终端、热敏小票机、桌号牌、菜单立牌、预约牌、服务铃、纸巾盒，共8款。设备屏幕、小票、纸巾和服务铃均为静态摆设。

空手点击桌号牌，选择“修改号码”后分别设置十位和个位，允许01—99，00无效。默认08，号码随摆设保存；收回只得到通用桌号牌，重新摆放恢复08。菜单中的“收回桌号牌”在背包满时保持原状。

`/function mcpe_food/tasting_new`取得本版8项；`/function mcpe_food/restaurant_accessories`取得5款餐厅用品；`/function mcpe_food/electronics`取得35款电子设备。餐厅用品位于创造物品栏“物品”页的新折叠组。

## 0.5.2角度与朝向修复

用户实机截图显示上一版屏幕向键盘前方倾斜。此前仅检查旋转参数的离线角度验证不足，本版将六款打开笔记本和iPad的屏幕倾斜直接写入几何坐标，最终屏幕不使用绕X轴的方块体旋转。生成后从模型坐标验证屏幕顶缘远离键盘前沿、内侧夹角110°；本次实机画面仍需复测。

所有电子设备使用东南西北固定方向。带屏设备按放置者位置选择最近的四向正面，不依赖玩家侧转的视角。已有0.5.1斜向记录会在加载时吸附到最近四向，位置、物品、款式与内容保留；没有yaw字段的旧摆件保留原来的四向。重新摆放按新规则选择正面，不持续跟随玩家。

升级时确认行为包和资源包均启用0.5.4。若仍显示旧模型，完全退出游戏后重新载入，并检查世界实际启用的包版本。

## 0.5.1内容与功能

- 戴尔银色轻薄本和深空黑MacBook Pro各提供打开／合起两款；戴尔显示纯Linux终端，MacBook Pro显示macOS桌面与ChatGPT窗口。均为固定画面，不连接网络或运行真实系统。
- 原银色轻薄本改为Win11风格桌面，原MacBook改为macOS桌面；其他旧设备色图保持不变。
- 六款打开笔记本与iPad的屏幕／键盘内侧夹角为110°。台式机、一体机的鼠标改到面对屏幕时的右侧，独立键鼠套装保留布局。
- 带屏设备新放置时按玩家位置选择最近的东南西北方向；保存后保持该方向。已有斜向角度记录在加载时吸附到最近四向，原有无角度记录保持既有四向。
- 新增玫瑰金、白、黑三色的双开门和单门冰箱，共6款。双开门高2格、单门高1格，只能放在完整支撑顶面；无储物、开门或制冷功能。双格结构需要整列空闲，破坏任一部件按模式只返还一次整台冰箱。
- 冰箱顶面可放餐具；拆除冰箱会同步清理依赖它的餐具、料理和广告画。创造破坏不掉落，生存及无法确定来源的支撑消失按原规则返还。
- 新增功夫茶盘套装，包含茶壶、公道杯和4只小杯，整套不可拆分；铁观音是独立饮品，可盛入玻璃杯或马克杯，不能从茶盘上的杯子取茶。
- 扩展至完整原版方块表面及原有半砖，广告画也支持玻璃等完整侧面；楼梯、箱子、栅栏、植物、流体和第三方方块不自动放行。持摆件点击顶面优先摆放，不打开支撑方块操作。

## 原电子设备

原有15个独立静态摆件：台式电脑套装、一体机套装、四款笔记本（银色轻薄本／游戏本／ThinkPad／MacBook，各有打开与合起两种）、四天线路由器、小型服务器机柜、iPad Air与妙控键盘、老式CRT显示器、键鼠套装。

所有设备占一格，支持四个朝向、完整支撑方块、书架和上下／双层半砖。手持物品点击支撑顶面放置；同一锚点位置只能放一件，上方被挡住时放置失败。带屏设备根据放置者的位置选择最接近的四向，方向保存后不跟随玩家移动；不再斜放。站在对角位置时选择最近的正面方向。电子设备以持久展示实体呈现，攻击摆件拆除，支撑方块保留；创造模式不消耗手持物品且拆除不掉落，生存模式按对应款式返还一次。命令或爆炸导致支撑丢失时沿用保全物品规则。

打开与合起的笔记本是不同物品，不提供点击开合、系统运行或联网功能。iPad Air包含横屏悬浮支架与妙控键盘，不额外生成键盘物品。空手或手持料理点击电子设备不改变设备，也不打开菜单。

设备使用128×128原创UV色图、图标和MER，金属机身、塑料、键帽与屏幕分别设定表面属性。仅亮屏画面与状态灯有低强度自发光，闭合笔记本全图无自发光；不添加方块光源或全局光照。未改动原版资源。

## 快速试用

在开启作弊的世界执行：

```mcfunction
/function mcpe_food/tasting_new
/function mcpe_food/tableware
/function mcpe_food/advertisements
/function mcpe_food/electronics
```

`tasting_new`提供本版8个新增物品，`electronics`提供全部35款电子设备，`restaurant_accessories`提供5款餐厅用品，每种4份。托盘、杯具和海报仍可通过原分组命令取得。另有完整五类命令：`tasting_all_chinese`、`tasting_all_western`、`tasting_all_japanese`、`tasting_all_dessert`、`tasting_all_drink`。中餐42、西餐23、日料13、甜品13、饮品11，共102种可食成品。

原细分系列命令继续可用，包括tasting_cantonese、tasting_huaiyang、tasting_seafood、tasting_french、tasting_hotpot等。give可能将背包溢出的物品掉到地上，请留出空间。

## 广告画

持广告画点击墙的侧面，选择尺寸。点击的方块作为画面的左下角，按照面对画面时的方向向右、向上展开，需要完整背墙和空闲前方空间。

| 比例 | 小 | 中 | 大 |
|---|---|---|---|
| 横幅2:1 | 2×1格 | 4×2格 | 6×3格 |
| 竖幅1:2 | 1×2格 | 2×4格 | 3×6格 |
| 方形1:1 | 1×1格 | 2×2格 | 3×3格 |

空手点击画面对应的墙面，打开调整尺寸／收回菜单。放大空间不足、与其他画重叠或背包满时保持原状。直接拆画时先移除广告画，背后的墙保留；拆除其他背墙支撑也会移除失去支撑的广告画。

这些是独立的广告物品与展示实体，不修改原版随机画。玻璃、矿石、红石与其他支持的完整原版方块可作为背墙，所有格子均需通过支撑检查。画面、文字、尺寸和完整ID见 [广告画目录](docs/ADVERTISEMENTS.md)。

## 餐具与三菜托盘

- 原盘装料理通用白瓷盘、黑金圆盘、酒红长盘；碗装料理通用青边瓷碗、黑金汤盅、酒红小碗。
- 手持成品点击空器皿盛装；空手点击取餐，留下实际使用的原款器皿与朝向。
- 三菜托盘占一格。手持盘装料理点击托盘，菜单选择左／中／右空盘；空手点击托盘，选择取回哪一份。
- 托盘支持70种盘装内容，含7种展示配菜。碗装汤饭、麻酱蘸碟和饮品使用原器皿。已占用的位置不能直接覆盖。
- 托盘取餐不额外生成普通盘；拆除时按规则返还托盘和实际剩余料理。
- 所有11款饮品可用玻璃杯或马克杯；仅“珍品红酒”另外适配高脚杯。纸杯是完整摆件，不提供倒入和喝取操作。
- 展示配菜、酒瓶、纸杯、筷子、刀叉、勺和铜锅不可食用；铜锅仍是静态桌景。

## 半砖与书架

餐具、盛装料理、托盘、铜锅、酒瓶、纸杯和电子设备均支持上述表面，每个位置仅允许一件摆设。下半砖使用独立展示实体，原半砖保留，模型和交互范围贴合半格高度。

将下半砖补成双层时，摆设会随表面升高；如果原有盛装方块的支撑变成下半砖，会保留菜品、器皿和方向并迁移为低位展示。上方被其他方块占用时不能放置。

在书架顶面放置本包餐具不会打开书架；其他书架交互保留。潜行时，在原有厨具顶面放置普通餐具继续使用原生放置。楼梯、栅栏和未知第三方半砖不在本次支持范围。广告画要求完整背墙，不使用半砖墙。

玩家创造破坏不掉落，生存破坏按实际内容返还。无法确定玩家来源的支撑消失（如命令或爆炸）按保全剩余物品处理。全部自定义方块保持零破坏碎屑。

## 光影与验证

资源包保留pbr能力，为方块和新增实体提供独立MER。海报和纸杯为非金属印刷面，酒液和食物无自发光；金属饰边、铜锅和刀叉保持独立属性。玻璃以细壁轮廓和几何空隙表现，不模拟真实折射。

在支持设备的视频设置中选择灵动视效。工程中的PBR结构检查不证明实机反光、透明排序或帧率，具体待验证场景见 [验证记录](docs/VALIDATION.md)。
