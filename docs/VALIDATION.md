# 0.5.2角度与四向修复验证

日期：2026-10-27。目标仍为基岩版国际版正式版26.52，稳定API 2.0.0，无需实验功能。

## 问题证据

用户提供的实机截图显示笔记本屏幕向键盘前沿倾斜。0.5.1测试从源旋转参数计算110°，没有识别游戏内实际姿态，因而不足以证明修复。截图平台和具体图像模式未确认。

## 本次修改与本地结果

- 六款打开笔记本和iPad的屏幕倾斜直接写入几何坐标，发行模型不再依赖屏幕绕X轴的原生方块体旋转。UV按原屏幕行分配，条带竖向不重叠，并错开铰链侧面共面接缝。
- 测试分别读取最终方块模型与实体模型，确认屏幕顶缘远离键盘前沿、中段几何轴与键盘夹角110°，而不是只检查rotation字段。七套完整模型均低于256个方块体。
- 带屏设备仅输出0、90、-90、-180四种yaw；按玩家相对位置选择最近正面，斜角位置选择最近四向，不持续跟随玩家。
- 已存电子设备斜向yaw在加载时一次性吸附，保留UID、位置、款式和内容；重复加载不重复增加revision。没有yaw的旧记录继续使用原direction。
- 严格编译通过，155项自动测试全部通过，1519998条静态断言通过。内容仍为197个物品、380个方块、865份模型、938份PNG、567份PBR纹理集，无新增物品。
- 保留0.5.1全部物品／方块ID、UUID、53个菜单配方、18个工作台配方、全部旧掉落、试用命令及作物状态。原版资源隔离、私有PBR和零破坏碎屑继续通过检查。

上述结果来自文件、几何和稳定API替身测试，不能替代客户端渲染验收。新的离线侧视图取自生成坐标，见previews/laptop_angles.png。
