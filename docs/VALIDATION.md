# 0.5.3屏幕修复与办公设备验证

日期：2026-10-28。目标为基岩版国际版正式版26.52，稳定API 2.0.0，无需实验功能。

## 问题与检查方法

路由器和服务器原来因无屏幕而跳过正面计算。本版将placementFront与screenFront分开，以指示灯／硬盘托架面选择最近四向。旧的无yaw记录按原direction恢复，重新放置才应用修复。

原MacBook的49条屏幕中有19条与外壳深度范围相交，仅检查共面和110°不足。本版使用共同Y网格、独立深度间隔与连续UV；预览还发现条带台阶缺面会从斜角露出壳体形成点阵，已补上对应屏幕行，完全隐藏面继续剔除。
