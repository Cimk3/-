# 方寸食光 / Food & Table 0.8.0

新增11个创造物品：实验设备8件，以及双屏、三联屏和45°竖屏显示器3件。

实验设备包含离心机、恒温培养箱、八盘位云储存阵列、开盘磁带录放机、无线电台、2×1吸顶悬臂显示器、数字示波器和移液器架套装。普通设备使用单格底座、最多两格高；设备、读数、转子、磁带、仪表与画面均为静态展示。

吸顶屏只支持点击完整天花板底面，以点击处为正面视角的左侧锚点，向右一格展开。需要上方两格完整支撑和下方2格宽、1格深、2格高的完整空间。空手点击任一安装支撑或显示实体可以收回整件；区块未加载时跳过清理。
