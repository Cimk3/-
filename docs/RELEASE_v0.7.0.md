# 方寸食光 / Food & Table 0.7.0

新增43个创造物品：医疗器械8款、娱乐设备3款、银行设备3款、AI工作设备4款、家电10款、教学设备3款，以及Template AI、Luna Studio（月-工作室）、FT电脑三幅纸面广告和9款固定电子广告屏。

## 使用

同时启用0.7.0行为包与资源包，创造模式运行`/function mcpe_food/tasting_new`取得43个新品。六类独立分组提供对应命令，`digital_ad_screens`发放9款电子屏。旧electronics命令保持原41项；6款冰箱在创造栏移入家电。

持壁挂物品点击完整墙面侧面，点击格为大屏左下角，向右上延伸；空手点击设备或背墙可收回。电子屏尺寸为宽×高：2×2、4×4、4×3，每种有三个固定品牌款，不轮播、不联网。

倒置楼梯的完整顶面可摆放，正放楼梯不开放。高设备需要上方两格空间；受阻、重叠或背墙不完整时保持原状。创造放置不消耗，玩家拆除不掉落。
