# 方寸食光 0.5.4

新增8款餐厅服务台摆件：触屏收银机、扫码支付终端、热敏小票机、可调桌号牌、菜单立牌、预约牌、服务铃、纸巾盒。电子设备共35项，新增餐厅用品分组5项。

桌号牌默认08，空手点击可用十位／个位选择01—99或收回；00无效，取消不变，号码随摆设保存，收回及破坏仅返还通用牌。其余物品均为固定展示，没有支付、打印、响铃或储物功能。

继续使用128px私有资源、PBR与零破坏碎屑，保留0.5.3所有ID、UUID、配方和旧368项展示索引。不覆盖原版材质、模型、贴图或光照。

## 安装与试用

导入FoodAndTable-0.5.4.mcaddon，在世界中同时启用0.5.4行为包和资源包。发行文件另含独立mcpack、源码ZIP及SHA256SUMS.txt。

`/function mcpe_food/tasting_new`发放8款新品；`/function mcpe_food/restaurant_accessories`发放5款用品；`/function mcpe_food/electronics`发放35项电子设备。
