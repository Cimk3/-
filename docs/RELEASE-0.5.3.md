# 方寸食光 0.5.3

新增7个静态办公设备，电子设备分组共32项：银色与灰色MacBook Air（仅打开，macOS与VS Code）、ThinkBook16+（银色开合两款，Win11桌面）、白黑打印扫描一体机、Mac Studio桌面套装（macOS剪辑界面）、Surface Pro键盘套装（Win11笔记界面）。所有屏幕均为固定画面。

修正路由器和服务器新放置时的正面选择：指示灯、硬盘托架朝向最近的四向玩家位置。旧摆件不自动翻转，重新放置应用新规则。

修正笔记本屏幕分条与外壳相交的问题：屏幕和外壳使用共用水平网格及明确深度间隔，连续分配UV；同时检查iPad、Surface Pro、摄像头和边框。打开的屏幕保持向后110°，不依赖原生X轴旋转。

继续使用128px私有资源与官方灵动视效PBR数据，不覆盖原版材质、模型、贴图或全局光照。新增设备沿用桌面支撑、持久保存与数量守恒流程，不提供真实系统、联网或打印扫描功能。

## 安装

导入`FoodAndTable-0.5.3.mcaddon`，在世界中同时启用0.5.3行为包和资源包。独立`.mcpack`、完整源码ZIP、SHA256SUMS.txt一并提供。

`/function mcpe_food/tasting_new`取得本版7个新增物品；`/function mcpe_food/electronics`取得全部32款电子设备。

## 验证边界

自动检查覆盖编译、模型遮挡与UV、110°角度、四向正面、表面支撑、占用与回滚、保存恢复、旧版兼容、资源隔离和发行归档。具体结果见源码中的`docs/VALIDATION.md`。

Windows、安卓、实际普通模式和灵动视效、真实联机及密集摆放性能未在实际Minecraft客户端运行。离线预览与模拟测试不能证明实际GPU闪烁已经消失，需要实机绕行及远近移动复测。
